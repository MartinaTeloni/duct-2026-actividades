# Analizador de Frecuencias
Este proyecto lee un archivo de texto (`texto_integradora.txt`), cuenta la frecuencia de las palabras ignorando mayúsculas y signos de puntuación, y genera un gráfico de barras con las 10 palabras más frecuentes en 'grafico_frecuencias.png'. 

## Dependencias
Para ejecutar este proyecto es necesario instalar 'matplotlib' y 'pytest'. Puedes instalarlas corriendo:
pip install matplotlib 
pip install pytest

## Cómo ejecutar
- Para ejecutar el analizador y generar el gráfico: `python analizador.py`
- Para correr los tests automáticos: `pytest`
